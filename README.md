# Pablo Mendes Faria

**Engenheiro de Dados | Python, SQL, BigQuery, Airflow, dbt | Analytics Engineering**

Desenvolvedor Python com foco em Engenharia de Dados, combinando pipelines ETL/ELT, modelagem dimensional, qualidade de dados, cloud e BI. Tenho base forte em backend, APIs e sistemas legados, o que me ajuda a construir solucoes de dados mais organizadas, automatizadas e sustentaveis.

Atualmente estou direcionando meu portfolio para projetos de dados ponta a ponta, com ingestao, transformacao, modelagem, validacao e consumo analitico.

## Projetos em Destaque

### MovieLens Beliefs Analytics

Pipeline analitico end-to-end para o dataset MovieLens Beliefs 2024.

- Ingestao de CSVs no GCS.
- Raw external tables no BigQuery.
- Staging tipado para limpeza e padronizacao.
- Marts dimensionais em modelo Kimball.
- Checks de qualidade e views de BI.
- Dashboard no Metabase com KPIs, rankings, heatmaps e analises de popularidade vs qualidade.

Links:
- [Case no portfolio](https://pablomendesfaria.github.io/portfolio/movielens.html)
- [Repositorio](https://github.com/pablomendesfaria/movielens)

### ComexData ETL

Pipeline para dados de comercio exterior brasileiro, com extracao da API Comex Stat, orquestracao em Airflow, transformacoes com dbt e armazenamento no Snowflake para consumo analitico.

Link:
- [Repositorio](https://github.com/pablomendesfaria/comexdata-etl)

### Korean Trade Scraper

Scraper assincrono para coleta de estatisticas de comercio internacional, usando Python, aiohttp, AsyncIO, Pandas e arquivos analiticos estruturados.

Link:
- [Repositorio](https://github.com/pablomendesfaria/korean-international-trade-scraper)
